# Proyecto SCRUM — Gimnasio ForceTech

Sistema de gestión para el Gimnasio ForceTech, desarrollado bajo el marco de trabajo SCRUM.

## Descripción
El proyecto consiste en el desarrollo de un sistema de información para el Gimnasio ForceTech que optimiza la gestión de clientes, servicios e instructores. La plataforma controla el proceso completo de inscripción (datos personales, estado y nivel de riesgo), la asignación de servicios (yoga, pilates, entrenamiento personalizado, piscina y gimnasio general) respetando sus capacidades máximas, y el seguimiento periódico del usuario a través de asistencias y evaluaciones físicas. Para ello, define tres roles de acceso: Cliente (consulta perfil y progreso), Instructor (dirige clases y registra avances) y Administrador (gestiona el sistema global); además, genera reportes clave sobre inscritos, ocupación de servicios, instructores activos, usuarios con bajo rendimiento o alto riesgo y el progreso individual de cada cliente.
